# Quick Party roadmap

## Next after v1.0.0

- [ ] Create a dedicated Quick Party icon for the minimap button and addon listing.
- [ ] Refine the UI: improve spacing, readability, and settings while preserving
  the native WoW look and quick access to the main actions.
- [ ] Add an easy way for players to submit feedback and report issues.
  Choose a feedback channel, link it from the addon, and explain what details
  help reproduce a problem, such as addon version, client build, and error text.
- [ ] Review player feedback and use it to prioritize further improvements.
